# 📖 About

Repository ini merupakan kumpulan materi, proyek, latihan, dokumentasi, dan eksperimen selama belajar di jurusan **TJKT (Teknik Jaringan Komputer dan Telekomunikasi)**.

Repository ini dibuat sebagai **portofolio belajar** sekaligus dokumentasi perjalanan menjadi seorang:

- 🌐 Network Engineer

- 🖥️ System Administrator
- 💻 Full Stack Developer
- 🤖 AI Developer
