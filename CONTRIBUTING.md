# 🤝 Contributing

Terima kasih atas ketertarikan Anda untuk berkontribusi.

## Cara Berkontribusi

1. Fork repository
2. Clone repository

```bash
git clone https://github.com/username/repository.git
```

3. Buat branch baru

```bash
git checkout -b feature-name
```

4. Commit

```bash
git commit -m "Add new feature"
```

5. Push

```bash
git push origin feature-name
```

6. Buat Pull Request

## Code Style

- Gunakan nama file yang jelas.
- Dokumentasikan setiap proyek.
- Gunakan Markdown untuk dokumentasi.
- Sertakan screenshot bila diperlukan.

Terima kasih atas kontribusinya.
